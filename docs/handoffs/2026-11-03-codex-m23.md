## What failed and what changed

Original CI run: https://github.com/Aulteran/FileCanopy/actions/runs/41569843848.
Six jobs passed; `e2e` and `compose (app)` each had two failures.

1. **Dialog keyboard focus:** native `<dialog>` made the background inert but Tab could leave the
   dialog for browser chrome. `apps/web/src/Dialogs.tsx` now cycles Tab/Shift+Tab at the first/last
   enabled, visible control. Escape, native modality and opener restoration remain in place. The
   existing accessibility e2e tests containment in both directions, Escape and focus return.
2. **First-run test order:** `test_accessibility.py` sorts before `test_browser_ui.py` and initializes
   the shared instance through `world`. The bootstrap browser test now uses a dedicated
   `fresh_stack` fixture with teardown, independent of session-stack initialization.
3. **Rename race:** the new test omitted required `expected_revision`, so it tested 422 validation
   failures. All six contenders now use the captured revision and must produce exactly one 200
   and five 409 responses for each of eight files. Listings must all succeed. Thread-pool futures
   propagate request exceptions to the main test; filesystem/DB consistency checks remain.
4. **Log canary:** `Client.call()` parses JSON, but the OIDC callback redirects to the HTML SPA.
   The test now uses `raw()`, verifies the HTML response and failed-login status, and requires both
   `/search` and `/auth/oidc/callback` in the logs before checking for leaked canaries.

Also diagnosed the earlier **Windows setup-token problem**: the test runner was reading the real
`deploy/.env`, whose fixed setup token suppresses generated-token logging. `Stack` now passes an
empty temporary `--env-file` and removes inherited `FILECANOPY_*` / `COMPOSE_*` configuration.
Tests deliberately set any overrides they need afterwards. Backup tests now reuse this runner
through `self.files` rather than duplicating the Compose command. The operator's `.env` is untouched.

`.prettierignore` and `.dockerignore` exclude `.claude/worktrees` so local Claude worktrees do not
fail formatting or enter Docker build contexts. No files in those worktrees were changed.
